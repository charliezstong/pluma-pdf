How to use Pluma PDF

  1. Choose your pages. Use selected frames or frames on the current page. Reorder with the arrows.
  2. Analyze and compare. Review the original PDF, the result, and the actual size of each page.
  3. Download. Change settings and analyze again using the originals already in memory.
Local engine

Install it once. Then open start-engine.command (macOS) or start-engine.cmd (Windows) and choose Connect local engine.

The download opens on GitHub. The installer requires Node.js 22.13 or later; PDFs are processed on your computer.

Smart optimizes PDF images without changing Figma assets. Unsupported images are preserved.

Compact turns each page into an image: text is no longer selectable. Original preserves the native export. Savings depend on the content.
